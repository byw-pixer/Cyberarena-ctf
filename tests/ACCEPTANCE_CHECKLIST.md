# Приёмка CYBERARENA

Результаты от 20.11.2026 для ветки `fix/acceptance-hardening`. Испытания с записью, рестартом и остановкой выполнялись в отдельных Compose-проектах на Arch Linux и Docker Engine 29.10.0 rootless. Основной экземпляр на порту 8080 оставался доступным. Оригинал ТЗ Школы 21 не предоставлен, сопоставление выполнено по требованиям задачи и прежнему чек-листу.

## Демонстрация на защите

1. Выполните `docker compose ps` и откройте главную на loopback. Покажите Nginx, платформу, лабораторию и две сети по схеме README.
2. В двух профилях браузера зарегистрируйте участников. Откройте каталог с тремя заданиями и ресурсы. Для ведущего используйте разборы из `writeups/`.
3. Покажите неправильный и правильный ответ, затем повторную отправку. Сверьте профиль и рейтинг.
4. Под учётной записью преподавателя создайте черновик и опубликуйте его. Покажите карточку во втором профиле.
5. На отдельном демонстрационном проекте снимите копию SQLite и покажите сохранность результатов после рестарта. Покажите штатный HTML 503 при остановке лаборатории и доступность остальной платформы.
6. Завершите офлайн-запуском из уже собранных образов и замером `docker compose stats --no-stream`. Инструкции по сбросу демонстрации и восстановлению есть в README.
