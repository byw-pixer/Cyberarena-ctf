# Чек-лист приёмки CyberArena

Заполняется при проверке. Пометки: OK / FAIL / дата. «Авто» значит, что пункт проверяют скрипты.

## Подготовка

```bash
./scripts/init-env.sh           # .env со случайными секретами
docker compose up -d --build
./scripts/seed.sh               # загрузить три задания в базу
```

## Автоматические проверки

| Проверка | Команда | Результат |
|---|---|---|
| Задания, шаблоны, загрузчик, стыки с backend, отсутствие флагов в публичных файлах | `python3 -m unittest discover -s tests -p "test_[ti]*.py" -v` | |
| Тесты backend (нужны зависимости: `pip install -r app/requirements.txt pytest httpx`) | `pytest -q` | |
| Инфраструктура, изоляция, отказоустойчивость, решаемость WEB-01 через Nginx | `./scripts/check.sh` | |

## Приёмочные испытания (раздел 10 ТЗ)

| № | Что проверить | Как | Результат |
|---|---|---|---|
| 1 | Платформа поднимается одной командой, открывается на localhost:8080 | `docker compose up -d --build`, браузер | |
| 2 | Преподаватель создаёт или редактирует задание, публикует, оно видно участнику | админка, затем вход участником | |
| 3 | Два участника регистрируются, входят, видят три задания, решают хотя бы по одному | вручную, два браузера | |
| 4 | Неверный флаг не даёт баллов | отправить `CTF{wrong}`, рейтинг не меняется | |
| 5 | Верный флаг начисляет ровно один раз | отправить верный флаг дважды, баллы один раз | |
| 6 | WEB-01 доступен через Nginx, лаборатория не имеет доступа к базе и Docker Socket | `./scripts/check.sh` | |
| 7 | Рейтинг верен и сохраняется после `docker compose restart` | решить, перезапустить, сверить | |
| 8 | Остановлена лаборатория: платформа и рейтинг работают, ошибка понятная | `docker compose stop lab-web`, открыть `/` и `/lab/` | |
| 9 | Демо работает без интернета | отключить сеть, `docker compose down && docker compose up -d` | |

## Тесты безопасности платформы (критические дефекты из ТЗ)

| № | Тест | Ожидаемо | Результат |
|---|---|---|---|
| S1 | Повторная отправка верного флага | баллы не растут | |
| S2 | Два одновременных запроса с верным флагом | баллы начислены один раз | |
| S3 | Обычный пользователь открывает админку и пробует изменить задание | 403, изменений нет | |
| S4 | Быстрая серия неверных флагов | срабатывает ограничение частоты | |
| S5 | Поиск флага в HTML и JSON платформы: `curl -s localhost:8080/ \| grep 'CTF{'` и то же для списка заданий | пусто | |
| S6 | Пароли в базе | только хеши Argon2id, не открытый текст | |
| S7 | Контейнер лаборатории не видит платформу, интернет и Docker Socket | `./scripts/check.sh` | |
| S8 | Флаги заданий не в окружении платформы | `./scripts/check.sh` | |
| S9 | Swagger/OpenAPI платформы не доступен снаружи | зависит от реализации backend | |
