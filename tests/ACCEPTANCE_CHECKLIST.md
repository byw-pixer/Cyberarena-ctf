# Чек-лист приёмки CyberArena

Заполняется при проверке. Пометки: OK / FAIL / дата.

## Подготовка

```bash
docker compose up -d --build
docker compose logs app           # логин teacher и случайный пароль в рамке из символов «=»
```

## Автоматические проверки

| Проверка | Команда | Результат |
|---|---|---|
| Backend, задания, шаблоны, инициализация и стыки | `pytest -q` | |
| Стек: доступность, изоляция, отказоустойчивость, ограничение частоты, ресурсы | `python tests/check_stack.py` | |

## Приёмочные испытания (раздел 10 ТЗ)

| № | Что проверить | Как | Результат |
|---|---|---|---|
| 1 | Платформа поднимается одной командой на чистой системе, открывается на localhost:8080 | `docker compose up -d --build`, браузер | |
| 2 | Преподаватель создаёт или редактирует задание, публикует, оно видно участнику | админка, затем вход участником | |
| 3 | Два участника регистрируются, входят, видят три задания, решают хотя бы по одному | вручную, два браузера (один в режиме инкогнито) | |
| 4 | Неверный флаг не даёт баллов | отправить `CTF{wrong}`, рейтинг не меняется | |
| 5 | Верный флаг начисляет ровно один раз | отправить верный флаг дважды, баллы один раз | |
| 6 | WEB-01 доступен через Nginx, лаборатория не имеет доступа к базе и Docker Socket | `python tests/check_stack.py` | |
| 7 | Рейтинг верен и сохраняется после `docker compose restart` | решить, перезапустить, сверить | |
| 8 | Лаборатория остановлена: платформа и рейтинг работают, ошибка понятная | `docker compose stop lab-web`, открыть `/` и `/lab/` | |
| 9 | Демо работает без интернета | собрать с интернетом, отключить сеть, `docker compose down` и `docker compose up -d` | |
| 10 | Пароль администратора запрашивается к смене при первом входе | войти как teacher | |
| 11 | Смена флага через `.env` | задать `WEB02_FLAG` в `.env`, `docker compose up -d`, старый флаг не принимается, новый принимается | |

## Тесты безопасности платформы

| № | Тест | Ожидаемо | Результат |
|---|---|---|---|
| S1 | Повторная отправка верного флага | баллы не растут | |
| S2 | Два одновременных запроса с верным флагом | баллы начислены один раз | |
| S3 | Обычный пользователь открывает админку и пробует изменить задание | 403, изменений нет | |
| S4 | Быстрая серия неверных флагов | срабатывает ограничение частоты (429) | |
| S5 | Поиск флага в HTML и JSON платформы: `curl -s localhost:8080/ \| grep 'CTF{'` и то же для `/challenges` после входа | пусто | |
| S6 | Пароли в базе | только хеши Argon2id | |
| S7 | Контейнер лаборатории не видит платформу, интернет и Docker Socket | `python tests/check_stack.py` | |
| S8 | Swagger/OpenAPI платформы не доступен | `curl -i localhost:8080/docs` возвращает 404 | |
