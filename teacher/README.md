# Материалы преподавателя

Здесь лежат write-up заданий. Участникам эта папка не показывается:
репозиторий для студентов должен быть без `teacher/`, либо весь репозиторий приватный.
Флаги в write-up демонстрационные (из `.env.example`). Перед реальным турниром смените их в `.env`
и запустите `python3 tasks/build_tasks.py`.
