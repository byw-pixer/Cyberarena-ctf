# WEB-02 «Сейф на JavaScript» (150 баллов, Web, лёгкая)

**Размещение:** статические файлы платформы, второй контейнер не нужен.
Страница: `/static/tasks/web02/index.html`, скрипт: `/static/tasks/web02/vault.js`.
**Флаг (демо):** `CTF{view_source_is_not_a_crime}`. Задаётся `WEB02_FLAG` в `.env`.

## Условие для участников
Страница просит код доступа, а проверка выполняется прямо в браузере. Изучите страницу и подключённые к ней
файлы, найдите ожидаемый код. Он и есть флаг.

## Идея
Проверка на стороне клиента ничего не защищает: всё, что отдано браузеру, можно прочитать.

## Решение
1. Открыть страницу, посмотреть исходный код (Ctrl+U) и найти подключение `vault.js`.
2. Открыть `vault.js`: массив `parts` из четырёх строк в base64.
3. Функция `expected()` склеивает декодированные части через `atob`.
4. Декодировать вручную или в консоли браузера:
   `["Q1RGe3ZpZXc=","X3NvdXJjZV8=","aXNfbm90X2E=","X2NyaW1lfQ=="].map(atob).join("")`
5. Получается флаг, сдать его на платформе.

## Безопасность задания
Страница не выполняет опасных действий и не обращается к серверу. Флаг в файле не лежит в открытом виде
(только в base64), но по замыслу восстанавливается из выданных файлов.

## Как сменить флаг
Задать новый `WEB02_FLAG` в `.env`, выполнить `python3 tasks/build_tasks.py`, пересобрать проект.

## Что проверено автоматически
`tests/test_tasks.py`: из `vault.js` восстанавливается именно флаг, в открытом виде его в файле нет.
