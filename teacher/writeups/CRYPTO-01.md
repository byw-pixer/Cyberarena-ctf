# CRYPTO-01 «Перехваченная записка» (150 баллов, Crypto, средняя)

**Размещение:** карточка платформы + текстовый файл `/static/tasks/crypto01/cipher.txt`.
**Флаг (демо):** `CTF{vigenere_needs_a_better_key}`. Задаётся `CRYPTO01_FLAG` в `.env`. Ключ шифра: `cyberarena`.

## Условие для участников
Скачайте шифротекст и расшифруйте записку. Подсказка: шифр использует повторяющийся ключ, а ключ это название
нашей платформы на английском языке строчными буквами. Знаки препинания не шифруются.

## Шифр
Шифр Виженера: каждая буква сдвигается на букву ключа, ключ повторяется. Шифруются только латинские буквы
(регистр сохраняется), остальные символы остаются на месте, поэтому структура `ХХХ{...}` видна.

## Решение
1. Понять, что это полиалфавитный шифр с повторяющимся ключом (подсказка в условии).
2. Ключ: `cyberarena`.
3. Расшифровать, например в Python:

```python
def decrypt(text, key):
    shifts = [ord(c) - 97 for c in key.lower()]
    out, i = [], 0
    for ch in text:
        if ch.isascii() and ch.isalpha():
            base = 65 if ch.isupper() else 97
            out.append(chr((ord(ch) - base - shifts[i % len(shifts)]) % 26 + base))
            i += 1
        else:
            out.append(ch)
    return "".join(out)

print(decrypt(open("cipher.txt").read().strip(), "cyberarena"))
```

4. Результат: `Intercepted note. The secret you are looking for is CTF{...}`. Сдать флаг.

Подойдёт и любой онлайн-декодер Виженера. Альтернатива без подсказки с ключом: известный открытый текст
(`The secret ...`) позволяет восстановить ключ.
