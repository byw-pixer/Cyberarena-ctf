# CYBERARENA — первый интерактивный макет v0.1

Первый **офлайн UX/UI-прототип** платформы для кейса «Школы 21». Создан с опорой на файл `Кейс Школа 21(1).pdf` (6 страниц) и обсуждения проекта. Статья Habr `https://habr.com/ru/articles/889556/` рассматривается как **каталог референсов CTF-сайтов**, а не как дополнительный набор требований.

## Как открыть

Дважды щёлкните по `index.html` в папке. Для просмотра **не нужны** Docker, Python, интернет, npm, CDN или внешний шрифт. Можно также запустить любой простой локальный HTTP-сервер для разработки.

## Что можно нажимать

- Обзор: переход в каталог и рейтинг, карточки 3 заданий.
- Каталог: переключение Web / Crypto, поиск, открытие задания.
- Карточка задания: условие, баллы, ссылка на демо-ресурс, поле `CTF{...}`.
- Рейтинг: демонстрационная таблица с сортировкой при равенстве баллов по времени.
- Профиль: стартовое состояние нового участника (0/3 заданий).
- Админка: создание/изменение/скрытие карточек **только в памяти вкладки**, тестовый сброс.
- Вход и регистрация: демонстрационный переход к профилю без серверной авторизации.
- Адаптивная боковая навигация для телефонов.

## Дизайн и рамки

Цвета: очень тёмный navy, lime green и холодный голубой. Шрифты системные. Структура предназначена для последующего переноса в **Jinja2 templates и отдельный CSS**.

**Это не готовая CTF-платформа:** никаких настоящих аккаунтов, проверок флагов, начислений, БД, HTTP-сервера `/lab/` или админских прав здесь нет. Флаги не добавлялись в HTML и JS. Примерные данные рейтинга нужны только для визуализации. Демо-файлы `resources/*` не являются тремя полноценными заданиями.

## Что делать дальше по ТЗ

1. Разделить `index.html` на Jinja2-макеты (base, dashboard, challenges, challenge_detail, leaderboard, profile, admin, auth).
2. Подключить FastAPI + SQLite/SQLAlchemy (User, Challenge, Submission, Solve).
3. Реализовать серверную аутентификацию, проверку CTF-флагов, защиту от повторного начисления и ограничение попыток.
4. В Docker Compose поднять nginx, app, lab-web. Только localhost:8080; изолированные app-net/lab-net.
5. Подготовить реальные WEB-01, WEB-02 и CRYPTO-01, отдельно закрытые от учеников write-up преподавателя.
6. Протестировать сквозной цикл, сохранность после рестарта и 5–10 участников.

Важное замечание: в реальной версии эндпоинты админки должны проверять роль **на сервере**, а введённый пароль никогда не должен храниться в браузерном JS.
